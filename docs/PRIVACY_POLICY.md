## 1. Executive Summary: Zero-Knowledge Architecture
**Dispatch** is designed with strict client-side data privacy principles:
- **No Remote Databases:** All spreadsheet records (`.xlsx`, `.xls`, `.csv`) are loaded directly into device volatile RAM memory.
- **No Third-Party Intermediary:** Phone numbers, balances, student names, and message bodies are never transmitted to any third-party analytics or intermediary server.
- **Direct Meta Integration:** When using the Official WhatsApp Business API, HTTP calls travel directly from your phone to Meta’s verified endpoints (`graph.facebook.com`) via TLS 1.3 encryption.

---

## 2. Information We Process
1. **Spreadsheet Data:** Used solely for local token resolution (`{{Name}}`, `{{Balance}}`, etc.) and campaign preparation.
2. **WhatsApp API Credentials:** Stored strictly on your local device in encrypted shared preferences.
3. **Offline Campaign History:** Stored locally on the user's phone for delivery reporting and auditable statistics.

---

## 3. Permissions Requested
- **Storage / Document Picker:** To allow the user to select and import spreadsheets.
- **Internet:** To dispatch official Meta WhatsApp Cloud API requests and open click-to-chat links.

---

## 4. Third-Party Services
- **WhatsApp & Meta Platforms, Inc.:** Messaging complies with WhatsApp Business Messaging Policies.
- **Zero Advertising Trackers:** No ad networks, tracking cookies, or analytics SDKs are bundled.
